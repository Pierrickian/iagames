Des jeux qui naissent d'une conversation.

IAGames imagine des jeux web sur mesure, pensés pour être joués rapidement puis améliorés par itérations.

La méthode est simple : partir d'une envie, trouver la règle juste, mettre en ligne un prototype, puis laisser le jeu grandir avec les retours.

Notre boussole : les joueurs créent les règles, les règles créent le jeu, le jeu crée un moment partagé.
