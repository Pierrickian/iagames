Une agence pour les jeux qui veulent grandir.

La promesse n'est pas de produire un gros jeu figé. La promesse est de trouver vite ce qui donne envie de jouer, puis de faire évoluer l'expérience par touches successives.

01

Les joueurs créent les règles

On part de vos mots, de votre univers, de vos références, de vos sensations. Même une phrase suffit à démarrer.

02

Les règles créent le jeu

On cherche la règle juste : celle qui crée la tension, le rire, la surprise, le risque ou l'envie de recommencer.

03

Le jeu crée un moment partagé

Le jeu doit être accessible par lien, montrable vite, testable avec des proches, et assez vivant pour appeler une suite.

Du speech-to-app, mais avec une âme de game designer.

Pour particuliers créatifs

Vous avez une idée de jeu, une blague, un défi familial, un concept étrange, une mécanique qui vous obsède. On en fait une première expérience jouable.

Pour projets qui cherchent leur gameplay

On prototype avant de trop produire. Le code sert à éprouver le plaisir de jeu, pas à enfermer l'idée dans un cahier des charges trop tôt.

Pour jeux évolutifs

Une arme, un boss, une balle, une règle, un niveau, une interface : chaque évolution peut devenir une nouvelle couche de plaisir.

Pour URL partageables

Le jeu vit en ligne. Pas d'installation obligatoire, pas de friction inutile : on clique, on joue, on comprend, on ressent.

Une méthode courte, presque ludique.

On garde l'élan. On transforme le flou en règles jouables, puis les retours en nouvelles versions.

1

Vous racontez

Un vocal, un texte ou une intuition : le point de départ reste simple et vivant.

2

On extrait la boucle

Objectif, action, contrainte, récompense, feedback. On trouve ce qui doit faire rejouer.

3

Le jeu arrive en ligne

Une page web jouable, responsive, partageable, avec une direction claire.

4

On fait évoluer

Les demandes deviennent des updates : gameplay, UI, niveaux, équilibrage, surprises.

Deux façons de commencer.
